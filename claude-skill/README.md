# RunCal Claude 스킬

PC(또는 폰)의 Claude에서 RunCal 일정을 자연어로 관리하기 위한 스킬입니다. 앱 코드와는 별개입니다.

## 올리는 방법 (claude.ai)

1. `runcal` 폴더를 zip으로 압축합니다(zip 안의 최상위에 `runcal/SKILL.md`가 있어야 합니다).
2. claude.ai → 설정 → 기능(Capabilities) → 스킬에서 zip을 업로드하고 켭니다.
3. 같은 화면에서 **Notion**과 **Google Calendar** 연동을 켭니다. Notion 연동에는 훈련일지 DB 접근을 허용합니다.

## 미리 확인할 것

- 스킬의 "구글 캘린더 일정 → 유형별 색" 표는 제안값입니다. 앱의 설정 > 일정 유형과 다르게 쓰고 있다면 표를 고쳐서 올리세요.
- Notion DB의 속성 이름(세션·날짜·상태·일지)이나 상태 값이 바뀌면 `SKILL.md`도 같이 고쳐야 합니다.
- 스킬은 쓰기 전에 항상 목록을 보여주고 확인을 받도록 되어 있습니다. 바로 실행하게 하려면 "변경 규칙" 1번을 고치세요(권장하지 않음).
