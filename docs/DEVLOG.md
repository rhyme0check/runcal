# RunCal 개발 기록

개인용 안드로이드 캘린더 앱. 폰의 모든 캘린더(삼성·구글 등)와 Notion DB를 한 화면·위젯에서 보고 관리한다.
배포용이 아니라 본인 폰(갤럭시 S23)에서 쓰는 앱이다.

- 기간: 2026-09-22 ~ 2026-10-03 (이후 실사용 점검)
- 기준 커밋: `40319e5`

## 쓰는 방식 (2026-10-03 기준 정리)

| 일정 | 들어오는 길 | 알림 |
|---|---|---|
| 달리기·글쓰기·독서모임 | Claude(PC·폰) → Notion → RunCal | RunCal의 Notion 알림(DB별 설정) |
| 회사 일정(대부분 1회성) | 폰에서 직접 등록(My calendar 등) | 캘린더 알림 |

- Notion → RunCal 반영: 앱을 열 때, 설정한 주기마다(1~12시간), 위젯 ↻
- RunCal을 그만 쓸 때를 대비해 매월 15일·말일 Notion 항목을 폰 캘린더(My calendar)에 복사
- Google 캘린더는 "Notion을 거치지 않는 일반 일정"을 볼 때만 쓴다. Claude → Notion → RunCal 경로에는 Google이 끼지 않는다.

## 구조 요약

- **화면:** 월간·일간·목록·설정(Compose). AI 명령(Gemini) 화면.
- **위젯 10종:** 월간 3종, 오늘 3종, 할일 4종(1x2·1x4·4x1·2x1). RemoteViews 직접 렌더링, 네트워크 없이 로컬만 읽는다.
  - 성능 기준: 앱을 띄워 둔 상태 350ms, 새로 띄운 직후 800ms. `renderMonthly perf` 로그와 350ms 초과 오류 기록은 지우지 말 것.
- **데이터 소스:**
  - CalendarContract: 폰의 모든 캘린더. 읽기·쓰기, 반복(RRULE)과 예외 처리
  - Notion: Room 캐시만 읽는다. 동기화는 WorkManager. DB별로 "앱에서 수정"을 켜면 날짜·상태만 PATCH
- **Room(v10):**
  - Notion 등록·캐시
  - 색 스타일, 로컬 일정 출처, 예약 알림, 공휴일·절기·음력
  - 일정그룹·지정, 생일·기념일 표시
  - 사용 기록·오류, Notion 복사 매핑
- **설정 저장:** DataStore(앱 설정·프리셋), SharedPreferences(위젯별 설정, 시각 표기, 복사 기록)
- **백업:**
  - 일일 로컬(7일 보존), 수동 파일, 30일 주기 Drive(appDataFolder)
  - 복원 전 자동 안전 백업
  - Notion 캐시·토큰은 백업하지 않는다.

### 색 우선순위

지금 보는 프리셋 색(켠 경우) → 일정그룹 색 → 개별 일정 색 → 캘린더(소스) 색.
기념일은 이 순서와 상관없이 공휴일 색이다.

### 프리셋

- 고른 캘린더·Notion DB의 일정에 고른 일정그룹의 일정을 더한 합집합을 보여 준다.
- 앱과 위젯이 같은 목록을 쓰고, 연동을 켜면 선택도 따라간다(위젯별 고정 가능).

### 이 기간에 고친 기존 버그
- Notion 종일 항목이 한국 시간에서 하루 앞에 보이던 문제(종일은 UTC 자정으로 통일)
- 주기 Notion 동기화 후 위젯이 다시 그려지지 않던 문제, 저장한 동기화 주기가 실제 예약에 반영되지 않던 문제
- 목록 화면이 수정 후에도 예전 값을 보이던 문제
- 지금 보는 프리셋을 고쳐도 필터가 바로 바뀌지 않던 문제
- 프리셋 편집 창이 스크롤되지 않아 캘린더가 많으면 잘리던 문제(실기기에서 발견)
- 시작 시 일정그룹 상태 초기화 순서 때문에 앱이 꺼질 수 있던 문제
- 로컬 일정 백업에 반복 규칙·메모가 빠져 있던 문제

## 운영 규칙

- `local.properties`(Notion·Gemini 키)는 git에 넣지 않는다. 값은 출력하지 않고, 있는지만 확인한다.
- 테스트는 에뮬레이터의 "RunCal 테스트" 로컬 캘린더로 하고, 끝나면 지운다.
  - 실제 구글 캘린더나 Notion 일지에는 쓰지 않는다(사용자가 허락한 실데이터 테스트는 예외, 끝나면 원상 복구).
- 단계마다 로컬 커밋한다. 커밋 메시지는 한국어로 쓰고, 끝에 Co-Authored-By 줄을 붙인다.
- 위젯 렌더링 경로에서는 네트워크를 쓰지 않는다. 캐시와 메모리 스냅샷만 읽는다.

## 빌드·설치

```
# JAVA_HOME = Android Studio 내장 JBR
gradlew.bat :app:assembleDebug            # → app/build/outputs/apk/debug/app-debug.apk
gradlew.bat :app:testDebugUnitTest        # 단위 테스트 13개
adb install -r app/build/outputs/apk/debug/app-debug.apk   # 데이터 유지 업데이트
```

같은 PC의 디버그 키로 서명한 APK끼리는 덮어 설치가 된다. 다른 키로 서명된 앱이 이미 깔려 있으면 지우고 다시 설치해야 한다(그 전에 앱에서 백업).
